# TrackTel — Brandbook

Брендбук учебного MVP-трекера привычек и задач TrackTel (Telegram Mini App).
Стиль: **«Telegram-нативный утилитарный минимализм»** — приложение живёт внутри
Telegram, поэтому визуально продолжает его систему, а не спорит с ней.

Принципы:

1. **Нативность.** Системный шрифт, синее семейство Telegram, светлая и тёмная темы.
2. **Скорость микро-действий.** Пользователь заходит на 10–30 секунд: крупная цель,
   мало элементов на экране, ничего лишнего.
3. **Спокойная поддержка, не геймификация.** Единственная «игровая» нота — серия
   (streak). Нет очков, уровней, мотивационных лозунгов.
4. **Один яркий акцент на экран.** Обычно это кнопка «Отметить» / «Создать».

Правила палитры:

- Акцентное семейство — только синее (светлая тема) / голубое (тёмная тема);
  не вводить второй акцентный цвет без необходимости.
- Семантические цвета (зелёный/красный/оранжевый) используются только по
  назначению: выполнено / опасно / предупреждение.
- Полупрозрачные оттенки (бейджи, просроченные карточки) — через
  `color-mix(in srgb, <цвет> N%, var(--surface))`, не отдельными hex.
- Контраст текста к фону — не ниже WCAG AA; светлая и тёмная темы проверены
  Lighthouse (Accessibility 1.0).

## 2. Типографика

Шрифт: **системный стек** (веб-шрифты не подключаются — экономия трафика и
точное совпадение с системой Telegram):

```
-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif
```

| Роль | Размер | Начертание | CSS-класс |
|---|---|---|---|
| Заголовок страницы | 28px | 700 | `.page__title` |
| Заголовок модалки | 20px | 700 | `.modal__title` |
| Заголовок привычки | 17px | 600 | `.habit__title` |
| Заголовок карточки-задачи | 16px | 600 | `.task__title` |
| Тело | 16px | 400 / 1.45 | `body`, `.text` |
| Мета-строка | 13–14px | 400, `--text-muted` | `.habit__meta`, `.task__meta` |
| Секция (капс) | 15px, uppercase, letter-spacing 0.03em | 600 | `.card__title` |
| Микро-подпись | 11–12px | 400–600 | `.tabbar__label`, `.summary__label` |
| Крупная метрика | 20–32px | 700–800 | `.summary__value`, `.summary__percent-value` |

Правила:

- Заголовки — без точек; подписи и подсказки — строчные.
- Допускается только один уровень «капс-секции» на блок.
- Числа отчётов (счётчики, проценты) — крупнее текста, это визуальные якоря.

## 3. Сетка и компоновка

- **Mobile-first.** Основной сценарий — смартфон в пределах 320–560px.
- **Колонка контента:** `max-width: 560px`, по центру; горизонтальные отступы 16px.
- **Вертикальный ритм:** шаг 4px; типовые отступы 8 / 10 / 14 / 16px;
  между карточками 14px.
- **Скругления:** карточки, кнопки, панель модалки — 14px (`--radius`);
  поля ввода и сегментированные контролы — 10px; бейджи, тост, серия — 999px.
- **Шапка:** sticky, высота ~44px + safe-area сверху; название слева, бейдж режима справа.
- **Таббар:** fixed снизу, высота 60px + safe-area снизу; 5 равных колонок;
  контент страницы имеет нижний паддинг, равный высоте таббара + 24px.
- **Модальное окно:** снизу (bottom sheet) на мобильном, по центру от 600px;
  максимум 92dvh, затемнение `rgba(0,0,0,0.45)`.
- **Тач-таргеты:** минимальная высота кнопок 48px, элементов навигации 48px.
- **Safe-area:** все фиксированные элементы учитывают `env(safe-area-inset-*)`.

## 4. Тон голоса (tone of voice)

- **Общение на «ты»** — как в самом Telegram.
- **Короткие глаголы и существительные:** «Создать», «Отменить», «На паузу».
- **Без мотивационных лозунгов, восклицаний и эмодзи** в интерфейсе.
- **Ошибки — нейтрально и с решением:** «Не удалось сохранить. Повторить»,
  не «Упс! Что-то пошло не так 😅». Каждое сообщение об ошибке содержит действие.
- **Пустые состояния — с направлением:** заголовок + короткое объяснение +
  кнопка действия (класс `.empty`).
- **Терминология едина:** «привычка», «задача», «отметка», «серия», «пауза».
  Не смешивать с «приветствиями», «делами», «чек-инами».

## 5. Иконки

- Стиль: **монохромные линейные (outline)**, обводка 1.8px, `stroke: currentColor`,
  `fill: none`, скругления концов — через SVG-иконки в `client/src/components/Icons.tsx`.
- Размер в таббаре — 22px; иконки наследуют цвет активного/неактивного состояния.
- **Никаких эмодзи как иконок** и никаких мультяшных/заливочных иконок.
- Иконка = минимум смыслов: галочка (выполнено), цикл (привычки), квадрат
  (задача), список (отчёты), шестерёнка (настройки).
- Декоративные иконки скрыты от скринридера (`aria-hidden="true"`);
  у иконочных безтекстовых кнопок обязательна `aria-label`.

## 6. Движение

- Переходы состояний — 100–200ms, `ease`; только `filter`, `opacity`, `transform`.
- Никаких параллаксов, длинных появлений и анимаций, мешающих скорому жесту.
- Индикатор неудачи/успеха — тост (2.5s), без модалок подтверждения для
  необратимых, но редких действий — подтверждение только при удалении.
